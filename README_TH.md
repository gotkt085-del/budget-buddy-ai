# Budget Buddy AI — คู่มือติดตั้งภาษาไทย

เว็บไซต์ผู้ช่วยด้านการบริหารงบประมาณสถานศึกษา ใช้ธีมสีน้ำเงิน–ทอง มีหน้า Dashboard, แชต AI, คลังความรู้ และรายการตรวจสอบเอกสาร

## สิ่งที่ต้องมี
- Node.js เวอร์ชัน 18 ขึ้นไป
- API key ของ OpenAI ที่มีสิทธิ์เรียกใช้งาน API และมีการตั้งค่าการชำระเงิน/เครดิตตามข้อกำหนดของผู้ให้บริการ
- อินเทอร์เน็ตสำหรับเรียก AI

## เปิดใช้งานในคอมพิวเตอร์
1. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. ติดตั้ง Node.js จากเว็บไซต์ทางการ `https://nodejs.org/`
3. เปิด Terminal / PowerShell ในโฟลเดอร์โปรเจกต์
4. ติดตั้ง dependencies:
   ```bash
   npm install
   ```
5. คัดลอก `.env.example` เป็นไฟล์ชื่อ `.env`
   - Windows PowerShell: `Copy-Item .env.example .env`
   - macOS/Linux: `cp .env.example .env`
6. เปิดไฟล์ `.env` แล้วแทน `ใส่_API_KEY_ของคุณที่นี่` ด้วย API key จริงของคุณ
7. เริ่มระบบ:
   ```bash
   npm start
   ```
8. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

**สำคัญ:** ห้ามเปิด `public/index.html` โดยดับเบิลคลิก เพราะแชต AI ต้องทำงานผ่านเซิร์ฟเวอร์ ห้ามใส่ API key ใน HTML หรือเผยแพร่ไฟล์ `.env`

## เผยแพร่เป็นเว็บไซต์ออนไลน์ (ตัวอย่าง Render)
1. สร้าง repository ส่วนตัวบน GitHub และอัปโหลดไฟล์โปรเจกต์ โดยไม่อัปโหลด `.env` หรือ API key
2. สร้าง Web Service บน Render แล้วเชื่อม repository
3. ตั้งค่า Build Command เป็น `npm install`
4. ตั้งค่า Start Command เป็น `npm start`
5. เพิ่ม Environment Variables ในหน้า Settings ของบริการ:
   - `OPENAI_API_KEY` = API key ของคุณ
   - `OPENAI_MODEL` = `gpt-4o-mini` (หรือรุ่นที่บัญชีของคุณรองรับ)
6. Deploy แล้วเปิด URL ที่แพลตฟอร์มให้มา

บริการโฮสต์และการใช้ API อาจมีค่าใช้จ่ายตามแพ็กเกจและปริมาณใช้งาน ตรวจสอบราคาและเงื่อนไขจากผู้ให้บริการก่อนเผยแพร่จริง

## การตรวจสอบระบบ
- เปิด `http://localhost:3000/api/health`
- `aiConfigured: true` หมายถึงพบ API key ในเซิร์ฟเวอร์ แต่ไม่ได้รับประกันว่าคีย์ยังใช้ได้หรือมีเครดิต
- หากพบ `AI_NOT_CONFIGURED` ให้ตรวจสอบไฟล์ `.env` และเริ่ม `npm start` ใหม่
- หากพบข้อผิดพลาดเกี่ยวกับ API key ให้ตรวจสอบคีย์ สิทธิ์ API และยอดใช้งานของบัญชี

## ข้อจำกัดและความปลอดภัย
- ระบบนี้เป็นรุ่นเริ่มต้น มีแชต AI จริงผ่าน API แต่ **ยังไม่มีระบบสมาชิก/เข้าสู่ระบบ, ฐานข้อมูลผู้ใช้, ประวัติสนทนาถาวร, อัปโหลดเอกสาร, RAG หรือการค้นเว็บอัตโนมัติ**
- คลังความรู้เป็นข้อความตัวอย่างทั่วไป ไม่ใช่ฐานข้อมูลระเบียบราชการที่อัปเดตอัตโนมัติ
- อย่าใส่ข้อมูลส่วนบุคคล ข้อมูลลับ หรือข้อมูลการเงินที่ไม่ควรส่งไปยังบริการภายนอก
- ต้องตรวจสอบคำตอบกับระเบียบ หนังสือเวียน และหน่วยงานต้นสังกัดฉบับปัจจุบันก่อนใช้ปฏิบัติงานจริง
- ก่อนใช้ในองค์กรจริง ควรเพิ่มระบบยืนยันตัวตน การจำกัดอัตราการเรียก API การบันทึกการใช้งาน และการควบคุมสิทธิ์เข้าถึง
